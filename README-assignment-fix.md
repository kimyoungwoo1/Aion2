# 아이온2 관리 — 불가능 복구 및 파티·징표 동시 배정

## 변경 내용

- 일정 선택지는 **미입력 / 오전 가능 / 오후 가능 / 가능 / 불가능** 순서입니다. 기본값은 미입력입니다.
- 「전체 참여 캐릭터」 각 행에서 **파티 위치 + 징표를 함께 선택**하고 **배정 저장**을 클릭합니다.
- 오른쪽 「파티 편성」의 해당 캐릭터 이름 왼쪽에는 배정된 징표가 표시됩니다. 징표 1~5, ★, ☠, ☾ 지원.
- 파티를 미배정으로 변경해도 참여자 징표는 보존되며, 징표를 '징표 없음'으로 저장하면 제거됩니다.
- 기존 파티 비고, 포스 1~4, 숙제 초기화(수/토 21시 어비스, 수 05시 나머지), 자동 일정 동기화는 유지합니다.
- 데이터베이스 테이블은 변경하지 않으므로 **추가 마이그레이션 불필요**합니다. 이전에 `0010_member_markers_abyss_reset.sql`이 적용되어 있어야 합니다.
- `wrangler.jsonc`, Secret, D1 ID는 ZIP에 포함하지 않았습니다.

## 적용 (Codespaces의 프로젝트 최상위에서)

```bash
unzip -o Aion2_Impossible_PartyMarker_Together.zip
npx wrangler deploy
```

확인: 성역 → 참여 일정에서 '불가능' 선택. 성역 → 참여자·파티 편성에서 슬롱의 징표/파티를 동시에 선택하고 배정 저장 후 오른쪽 파티의 징표 표시 확인.

주의: 기존 공용 접속 코드는 닉네임 사칭을 막지 않으며 개인 숙제 접근도 같은 닉네임을 기준으로 제한됩니다.
