# 아이온2 관리 — 캐릭터별 비고

## 변경 내용
- 파티 카드의 **파티 비고 입력창을 제거**했습니다.
- 각 성역의 '참여자 · 파티 편성' → **전체 참여 캐릭터**에서 **캐릭터별 비고(최대 150자)**를 직접 입력하고 저장합니다.
- 오른쪽 파티 편성에는 저장된 **캐릭터 징표 + 닉네임 + 캐릭터 정보 + 비고**가 표시됩니다.
- 비고는 성역별 캐릭터 ID에 저장하므로 **파티를 옮겨도 그대로 유지**되고, 다른 캐릭터를 선택하면 그 캐릭터의 비고가 표시됩니다.
- 캐릭터를 연결하지 않은 참여자는 먼저 캐릭터를 선택해야 비고를 저장할 수 있습니다.
- 이전 버전의 파티 비고 기록은 DB에 남겨 두지만 새 화면에는 표시하지 않으며 자동 이전하지 않습니다. 파티 메모를 특정 캐릭터에게 임의로 배정하지 않기 위해서입니다.
- 기존 일정(미입력/오전 가능/오후 가능/가능/불가능), 징표·파티 배정, 캐릭터, 숙제, 초기화, 로그인, Cloudflare 설정을 변경하지 않았습니다.

## 적용 순서 (Codespaces의 프로젝트 최상위 폴더)

```bash
unzip -o Aion2_Character_Notes_PerMember.zip
npx wrangler d1 migrations apply aion2-db --remote
npx wrangler deploy
```

주의: 이번 업데이트는 **새 D1 테이블이 필요**합니다. 마이그레이션을 먼저 적용하세요. 기존 `wrangler.jsonc`와 `ACCESS_CODE`는 ZIP에 포함하지 않았습니다.

확인: 4성역 → 참여자·파티 편성 → 슬롱 행에서 캐릭터 연결/비고 저장 → 파티에 배정된 슬롱 아래에서 비고 표시. 다른 파티로 옮겨도 유지되는지 확인하세요.
