# 아이온2 관리 — 미입력 기본 / 징표 개인별 / 전체 참여 간소화 / 어비스 회랑 주 2회

ZIP 내부에 `aion2/` 최상위 중복 폴더가 없으며, 기존 프로젝트 파일에 덮어씁니다.

## 변경 내용

- 새로 시작한 주간 일정은 전부 `미입력`이 기본값입니다. 기존 저장된 값은 임의 변경하지 않습니다.
- 징표는 **성역별 고정 참여자**마다 관리합니다. `전체 참여 캐릭터`의 각 행에서 캐릭터/징표/파티를 선택합니다. 파티 카드에서는 징표를 **표시만** 하며 선택 기능은 없습니다.
- 파티별 징표는 더 이상 사용하지 않으며 **파티별 비고는 유지**합니다.
- 전체 참여 캐릭터는 한 참여자당 한 줄의 간결한 배치로 변경했습니다. 포스는 4개, 파티는 포스당 2개, 파티당 5명 그대로입니다.
- 어비스회랑은 **매주 수요일·토요일 21:00 KST**에 초기화됩니다. 다른 7개 숙제와 4/3/2성역 일정은 **수요일 05:00 KST**에 초기화됩니다. 과거 완료 기록은 보관하지 않습니다.
- 기존 영구 저장 어비스회랑 기록은 마이그레이션 실행 시점의 어비스회랑 주기로 한 번 이전되며, 다음 리셋 때 자동으로 초기화됩니다.
- 닉네임 로그인 / D1 / AION_API / ACCESS_CODE / 기존 파티 편성 보존.

## Codespaces 적용

```bash
npx wrangler d1 export aion2-db --remote --output=../aion2-db-before-abyss.sql
unzip -o Aion2_Compact_Markers_Abyss_Reset.zip
python3 scripts/enable-abyss-reset.py
npx wrangler d1 migrations apply aion2-db --remote
npx wrangler deploy
```

`wrangler.jsonc`는 ZIP에 포함되지 않아 **기존 UUID, 서비스 바인딩, Secret은 덮어쓰지 않습니다.** 스크립트는 기존 Cron 설정을 보존하고 `0 12 * * WED,SAT`만 추가합니다. 이미 있던 `0 20 * * TUE`는 그대로 유지합니다.

**주의:** 실제 개인정보 보호는 제공되지 않습니다. 기존 공용 접속 코드와 닉네임 로그인은 닉네임 사칭이 가능하며, 개인 숙제는 기존과 같이 로그인 닉네임으로 필터링됩니다.
