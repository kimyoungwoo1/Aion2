# 아이온2 관리 — 파티 먼저 / 캐릭터 비고 통합 저장

## 바뀐 기능

- **파티 편성**을 위쪽에 먼저 표시합니다. 파티 목록에서 징표, 캐릭터명, 그 **바로 아래 캐릭터 비고**, 직업·레벨·남툴을 볼 수 있습니다.
- 잘 변경하지 않는 **전체 참여 캐릭터**는 아래쪽의 펼침/접기 패널로 옮겼습니다. 기본 접힘이며 '전체 참여 캐릭터'를 눌러 펼칩니다.
- 참여 캐릭터 편집 행의 **파티 위치 + 징표 + 비고**를 **변경사항 저장** 버튼 하나로 저장합니다. 이 셋은 서버에서 하나의 D1 batch 트랜잭션으로 처리합니다.
- 캐릭터 선택(연결)은 이전처럼 선택 즉시 별도 저장됩니다. 비고가 없는 캐릭터는 비고 공란으로 둡니다.
- 캐릭터 비고는 기존대로 캐릭터 ID와 성역에 연결되어 파티가 변경되어도 유지됩니다. 기존 파티 배정·징표·비고 DB는 삭제하지 않습니다.

## Codespaces에 적용

프로젝트 최상위 `/workspaces/Aion2`에 ZIP을 업로드한 다음:

```bash
unzip -o Aion2_Party_First_Combined_Save.zip
npx wrangler deploy
```

이번 버전은 파일 3개(`public/index.html`, `public/app.js`, `src/index.js`)만 수정하며 **새 DB 마이그레이션이 없습니다**. 기존 `wrangler.jsonc`, D1 ID, `ACCESS_CODE`, 성역 주간 초기화 설정과 숙제 기능은 그대로 유지합니다.

사이트에서 4성역 → 참여자·파티 편성 → 아래쪽 ‘전체 참여 캐릭터’ 펼치기 → 슬롱의 파티·징표·비고 입력 → **변경사항 저장**으로 확인하세요. 파티 편성에 캐릭터 이름 아래 비고가 표시됩니다.
