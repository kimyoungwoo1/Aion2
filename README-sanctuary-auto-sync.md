# 아이온2 관리 - 성역 일정 자동 연동 및 전원 가능 요일

## 적용 방법

기존 `/workspaces/Aion2` 최상위에 ZIP 업로드 후:

```bash
unzip -o aion2-sanctuary-auto-sync.zip
npx wrangler deploy
```

기존 `wrangler.jsonc`, DB, 캐릭터 정보, 접속 코드, 마이그레이션은 변경하지 않습니다.

## 기능

- **4성역 델트라스 ↔ 3성역 무스펠:** 같은 닉네임, 같은 주차에 서로 연동합니다.
- 한쪽에만 일정이 있으면 다른 쪽 탭을 열 때 **요일이 자동 채워집니다.** 별도 가져오기 버튼이 없습니다.
- 단, 다른 성역에 **참여자로 자동 등록하지 않습니다.** 그 성역에도 참여할 경우 기존 `내 일정 저장`을 누르면 등록됩니다.
- 두 성역에 등록된 뒤에는 어느 쪽에서 수정하여 저장해도 요일별 가능 여부가 양방향 동기화됩니다.
- 비고는 성역별로 별도 보관하며, 2성역 침식은 독립 관리합니다.
- 날짜별 참여 가능 인원 카드 하단에 **다같이 가능한 요일**을 오전/오후로 구분하여 표시합니다.
  - 오전: 등록된 전원이 `가능`
  - 오후: 등록된 전원이 `가능` 또는 `오후 가능`
  - 미입력/불가능이 한 명이라도 있으면 해당 시간은 제외하며, 등록자가 0명이면 `없음`입니다.

참고: 공동 접속 코드 + 닉네임 체계이므로 동일 닉네임으로 접속한 사용자가 해당 참여 일정을 수정할 수 있습니다.
