# 아이온2 관리: 이번 주 일정 + 개인 숙제

이 압축파일은 **최상위 하위폴더 없이** 압축 해제하는 패치입니다. `wrangler.jsonc`는 포함하지 않아 기존 DB, 서비스 바인딩, Secrets 설정을 유지합니다.

## 적용

```bash
unzip -o Aion2_Weekly_Homework_20261029.zip
python3 scripts/enable-weekly-reset.py
npx wrangler d1 migrations apply aion2-db --remote
npx wrangler deploy
```

`wrangler.jsonc` 파일은 자동 백업 `wrangler.jsonc.backup`이 생성되며, 기존 바인딩과 `secrets.required`는 보존됩니다. `triggers.crons`에 `0 15 * * SUN`이 추가됩니다(한국시간 월요일 00:00). Cloudflare Cron은 UTC이고 실행이 지연될 수 있어, 앱의 API에서도 이전 주차를 표시하지 않고 이전 기록을 삭제합니다.

```bash
npx wrangler secret put HOMEWORK_ADMIN_CODE --name aion2
```

**운영자 코드**는 길고 무작위로 정해주세요(16자 이상). 기존 `ACCESS_CODE`는 변경하지 않습니다. `HOMEWORK_ADMIN_CODE`를 Github/코드에 직접 넣지 마세요. 운영자는 숙제 탭 하단 '운영자: 개인 잠금 코드 발급/재발급'에서 닉네임과 각자의 개인 잠금 코드(10자 이상)를 발급합니다. 사용자에게 개인 코드를 각각 안전하게 전달하세요. 사용자는 숙제 탭에서 자기 코드를 입력한 뒤 숙제를 관리할 수 있습니다.

## 동작
- 메뉴: 캐릭터 관리 → 4성역 델트라스 → 3성역 무스펠 → 2성역 침식 → 숙제
- 두 개의 성역 하위 탭을 가로 50:50으로 크게 표시
- 성역 참여 일정: 이번 주만 사용. 이전·다음 주 버튼 제거. 월요일 00시 한국시간 자동 초기화, 고정 참여자/파티는 유지
- 숙제: 캐릭터 소유자(`owner_name`)가 현재 닉네임과 같은 캐릭터만 표시. 목록·변경 API 모두 **닉네임 + 개인 잠금 세션** 확인 후 접근
- 숙제 8개: 어비스회랑, 각성전, 루드라, 침식, 무스펠, 델트라스, 시련, 오드구매&제작
- 숙제 기록도 매주 월요일 초기화. 이전 주 내역 보관하지 않음
- 4성역↔3성역 공통 참여자 일정 자동 동기화, 2성역 독립. 기존 기능 유지

## 보안 필독
공용 로그인에서 닉네임을 자유롭게 변경할 수 있으므로 **닉네임만으로 개인 데이터 보호가 불가능합니다.** 이번 패치는 숙제 접근에 추가 개인 코드와 별도 HttpOnly 쿠키가 필요하도록 하며 API 서버가 소유자를 검증합니다. 타인의 개인 코드를 알거나 탈취한 사람은 접근할 수 있으니 공유하지 마세요. 운영자 코드는 관리자만 보관하고 추측하기 어려운 값으로 설정하세요. 5회 잘못 입력하면 15분 잠깁니다. 중요한 개인정보 저장 목적이라면 추후 개별 계정/SSO 전환을 권장합니다.
